# Création un site web Trouver mon Artisan CEF avec React - Fatima Hitache

Bienvenue sur le projet de trouver mon artisan.
Ce fichier indique comment installer et créer ce projet.

## IDE utilisé pour ce projet

VS code + Node.js

## Installation :
Dans un terminal tapper la commande suivante :
### `npx create-react-app projet-bilan-trouver-mon-artisan`

Pour s'acceder au dossier du projet
### `cd mon-app`

Lancer le projet dans le navigateur
### `npm start`

Runs the app in the development mode.\
Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

The page will reload when you make changes.\
You may also see any lint errors in the console.

Installet les routes
### `npm install react-router-dom`



pour maildev :
## installer maildev en tapant la commande :
### `npm install npm@latest -g`

dans un terminale1 :
`maildev` => localhost1080 (Interface pour afficher les e-mails)

dans un terminal2 :
`node server.js` => localhost 3001 ( le formulaire sera fonctionnel)
